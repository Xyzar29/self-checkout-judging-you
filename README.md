One funny line in the voice of a smug self-checkout machine, judging a shopper who bought twelve yoghurts and nothing else — no spoon, no bag, no plan. The machine flags the basket as a cry for help and, in the ultimate insult, tells the shopper to go see a human.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (108 characters, well inside the 200-character gate), deterministically — the same bytes on every run.
